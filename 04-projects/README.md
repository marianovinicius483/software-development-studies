# Projetos de Desenvolvimento de Software

Esta seção reúne projetos práticos desenvolvidos durante minha formação acadêmica e em estudos pessoais.

Os projetos podem incluir aplicações, sistemas, APIs, aplicativos mobile, experimentos com inteligência artificial e outras soluções de software.

## Organização

04-projects/
└── nome-do-projeto/
    ├── README.md
    ├── docs/
    ├── src/
    └── tests/

Cada projeto terá seu próprio diretório.

Exemplo:

04-projects/
└── nome-do-projeto/
    ├── README.md
    ├── docs/
    │   ├── BRD.md
    │   ├── SRS.md
    │   ├── TDD.md
    │   ├── RFC/
    │   ├── ADR/
    │   └── tests/
    ├── src/
    └── tests/

A estrutura será adaptada conforme a complexidade e as necessidades de cada projeto.

## Documentação

Projetos relevantes poderão utilizar documentação de Engenharia de Software, como:

- README.md
- BRD — Business Requirements Document
- SRS — Software Requirements Specification
- TDD — Technical Design Document
- RFC — Request for Comments
- ADR — Architecture Decision Record
- Plano e casos de teste
- Registros de decisões técnicas

Nem todo projeto precisará de todos esses documentos. A documentação será definida de acordo com o tamanho, complexidade, objetivo e contexto do projeto.

## Tipos de projetos

- Projetos acadêmicos
- Projetos pessoais
- Aplicações
- APIs
- Aplicativos mobile
- Sistemas web
- Experimentos com inteligência artificial
- Outros projetos de desenvolvimento de software

## Objetivo

Aplicar na prática os conhecimentos de programação e Engenharia de Software, acompanhando minha evolução desde o planejamento e levantamento de requisitos até a implementação, testes e documentação.
