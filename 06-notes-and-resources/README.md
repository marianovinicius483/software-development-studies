# Anotações e Recursos de Estudo

Esta pasta reúne anotações, resumos e recursos úteis para consultar durante meus estudos de desenvolvimento de software.

## O que guardar aqui?

- Resumos de conteúdos estudados.
- Anotações sobre conceitos importantes.
- Links para documentações oficiais.
- Tutoriais e materiais de referência.
- Boas práticas de programação.
- Comandos e ferramentas úteis para desenvolvimento.

## Como organizar?

Os materiais serão separados por assunto ou tecnologia, facilitando a consulta e a revisão dos conteúdos.

Exemplo:

```text
06-notes-and-resources/
├── README.md
├── git-and-github/
├── software-engineering/
├── javascript/
└── programming-resources/
```

## Boas práticas

- Escrever anotações com minhas próprias palavras.
- Registrar exemplos que facilitem o entendimento.
- Priorizar documentações oficiais e fontes confiáveis.
- Manter os links e materiais organizados.

## Objetivo

Construir uma base de conhecimento pessoal que facilite a revisão dos conteúdos e sirva como referência durante o desenvolvimento de projetos.
