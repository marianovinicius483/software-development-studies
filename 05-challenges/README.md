# Desafios de Programação

Esta pasta reúne desafios de programação que resolvo para desenvolver meu raciocínio lógico e melhorar minha capacidade de solucionar problemas.

## O que guardar aqui?

- Desafios de plataformas de programação.
- Problemas de lógica e algoritmos.
- Listas de exercícios desafiadores.
- Problemas de competições de programação.
- Soluções que utilizam diferentes conceitos e técnicas.

## Como organizar?

Os desafios serão separados por plataforma ou origem. Cada desafio poderá ter seu próprio arquivo ou diretório, conforme sua complexidade.

Exemplo:

```text
05-challenges/
├── README.md
├── beecrowd/
│   ├── README.md
│   └── problem-1001.js
├── leetcode/
│   ├── README.md
│   └── two-sum.js
└── other-challenges/
    └── problem-01.js
```

## Boas práticas

- Ler e compreender o enunciado antes de programar.
- Planejar uma solução antes de escrever o código.
- Testar a solução com diferentes entradas.
- Escrever código legível e organizado.
- Registrar a origem do desafio e o que aprendi com ele.

## Objetivo

Praticar a resolução de problemas, fortalecer o raciocínio lógico e desenvolver soluções cada vez mais claras e eficientes.
