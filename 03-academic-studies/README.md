# Estudos Acadêmicos

Esta seção reúne materiais, atividades e documentos relacionados à minha formação acadêmica em desenvolvimento de software.

## Conteúdos

- Engenharia de Software
- Levantamento e análise de requisitos
- Modelagem de sistemas
- Documentação de software
- Atividades e exercícios das disciplinas

## Objetivo

Registrar e organizar os conhecimentos adquiridos durante a faculdade, aplicando boas práticas de engenharia de software.
