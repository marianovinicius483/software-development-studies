# Software Development Studies

Repositório pessoal dedicado aos meus estudos em desenvolvimento de software.

## Objetivos

- Desenvolver minha lógica de programação.
- Praticar exercícios em diferentes linguagens.
- Registrar atividades e conteúdos da faculdade.
- Construir projetos práticos.
- Acompanhar minha evolução como desenvolvedor.

## Estrutura do repositório

| Diretório | Conteúdo |
|---|---|
| `01-fundamentals/` | Lógica e fundamentos da programação |
| `02-programming-languages/` | Exercícios por linguagem |
| `03-academic-studies/` | Estudos e atividades acadêmicas |
| `04-projects/` | Projetos práticos |
| `05-challenges/` | Desafios de programação |
| `06-notes-and-resources/` | Anotações e recursos de estudo |

## Tecnologias em estudo

- JavaScript
- SQL
- Outras linguagens e tecnologias conforme o avanço dos estudos.

## Progresso

Este repositório será atualizado continuamente durante minha formação acadêmica e prática em desenvolvimento de software.
