# Linguagens de Programação

Esta seção reúne exercícios, exemplos e projetos organizados por linguagem.

## Linguagens em estudo

- JavaScript
- Python
- Java
- SQL

## Organização

Cada linguagem terá seu próprio diretório, com exercícios separados por assunto e nível de aprendizado.

## Objetivo

Praticar a sintaxe, os conceitos fundamentais e a resolução de problemas em diferentes linguagens.
