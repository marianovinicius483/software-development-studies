# Variáveis e Tipos de Dados

Esta seção reúne exercícios sobre declaração de variáveis, constantes e tipos de dados em JavaScript.

## Conteúdos

- `let` e `const`
- Strings e números
- Booleanos
- Operadores aritméticos
- Conversão de tipos
- `typeof`

## Prática

Os exercícios serão registrados conforme forem estudados, incluindo exemplos, soluções e aprendizados.
