# Mini Projetos em JavaScript

Esta seção reúne pequenos projetos desenvolvidos para aplicar os conhecimentos adquiridos durante os estudos.

## Ideias de projetos

- Calculadora simples
- Verificador de aprovação escolar
- Sistema de cadastro de tarefas
- Jogo de adivinhação
- Controle de inventário
- Gerador de relatórios simples

## Objetivo

Aplicar os fundamentos de JavaScript na resolução de problemas práticos, desenvolvendo o raciocínio lógico e a organização do código.

## Prática

Cada projeto terá seus próprios arquivos, descrição do problema, funcionalidades e aprendizados.
