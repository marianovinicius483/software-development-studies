# Estruturas Condicionais

Esta seção reúne exercícios de tomada de decisão em JavaScript.

## Conteúdos

- `if`
- `else`
- `else if`
- Operadores de comparação
- Operadores lógicos
- Condições compostas

## Objetivo

Aprender a controlar o fluxo de um programa com base em condições.

## Prática

Os exercícios serão organizados conforme o avanço dos estudos, com exemplos, tentativas e correções.
