# Laços de Repetição em JavaScript

Esta seção reúne exercícios sobre repetição de instruções e controle de ciclos.

## Conteúdos

- `for`
- `while`
- `do...while`
- `break`
- `continue`
- Contadores e acumuladores
- Laços aninhados

## Objetivo

Aprender a automatizar tarefas repetitivas e controlar a execução de ciclos em JavaScript.

## Prática

Os exercícios serão organizados conforme o avanço dos estudos, com exemplos, tentativas e correções.
