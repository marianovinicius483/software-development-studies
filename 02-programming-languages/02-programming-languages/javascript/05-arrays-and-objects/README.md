# Arrays e Objetos em JavaScript

Esta seção reúne exercícios sobre armazenamento, organização e manipulação de dados.

## Conteúdos

- Criação e acesso a arrays
- Índices e propriedades `length`
- Métodos `push`, `pop`, `shift` e `unshift`
- Métodos `includes` e `indexOf`
- Criação e acesso a objetos
- Propriedades e métodos de objetos
- Iteração e manipulação de dados

## Objetivo

Aprender a organizar coleções de dados e manipular suas informações usando JavaScript.

## Prática

Os exercícios serão registrados conforme o avanço dos estudos, incluindo tentativas, correções e aprendizados.
