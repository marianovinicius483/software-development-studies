# Funções em JavaScript

Esta seção reúne exercícios sobre criação, chamada e utilização de funções.

## Conteúdos

- Declaração de funções
- Parâmetros e argumentos
- `return`
- Funções com condições
- Funções com arrays e objetos
- Funções anônimas e arrow functions

## Objetivo

Aprender a dividir programas em partes reutilizáveis, organizadas e fáceis de testar.

## Prática

Os exercícios serão registrados conforme o avanço dos estudos, incluindo tentativas, correções e aprendizados.
